# OPE-157 — Trend Finder: AliExpress & Alibaba Product Research App

Веб-аплікація для пошуку трендових товарів на **AliExpress** та **Alibaba** через Apify API. Дозволяє досліджувати ринок, переглядати топ товари по категоріях, аналізувати ціни та рейтинги.

## Мета

Автоматизувати процес:
1. Пошуку трендових товарів на AliExpress і Alibaba
2. Відображення та аналізу результатів (ціна, рейтинг, замовлення)
3. Побудови графіків для дослідження ринку

## Архітектура

```
[Browser] → [Next.js App Router]
                │
                ├── [/api/search Route Handler]  ← серверний проксі
                │         │
                │         ├── [Apify: AliExpress Scraper]
                │         └── [Apify: Alibaba Scraper]
                │
                ├── [React Query]  ← кешування, retry, стан
                ├── [nuqs]         ← URL state sync
                └── [Recharts]     ← графіки
```

## Як це працює

### 1. Пошук товарів
- Користувач вводить запит і обирає платформу (AliExpress / Alibaba / обидві)
- Форма валідується через zod (regexp, довжина, допустимі символи)
- Стан пошуку синхронізується з URL через nuqs (посилання можна зберігати і ділитися)

### 2. Серверний Route Handler `/api/search`
- Перевірка rate limit (10 запитів/хв на IP)
- Валідація вхідних параметрів через zod
- Якщо `APIFY_API_TOKEN` не встановлено — повертає mock дані (demo mode)
- Паралельний запуск обох actors через `Promise.allSettled`
- Нормалізація відповідей до єдиного формату `Product`

### 3. Відображення результатів
- Три режими перегляду: Картки / Таблиця / Графіки
- Skeleton UI під час очікування (Apify може відповідати 5–15 сек)
- Пагінація результатів
- Детальна картка товару (ProductModal) при кліку

## Режими відображення

| Режим | Desktop | Mobile |
|---|---|---|
| Картки | Grid 4 колонки | Grid 2 колонки |
| Таблиця | Повна таблиця | Fallback на картки |
| Графіки | Grid 3 колонки | Стек в один рядок |

## Змінні середовища

```
APIFY_API_TOKEN=            # серверна, обов'язкова для real data
UPSTASH_REDIS_REST_URL=     # серверна, для rate limiting у production
UPSTASH_REDIS_REST_TOKEN=   # серверна, для rate limiting у production
```

> ⚠️ Без `APIFY_API_TOKEN` додаток запускається в **Demo Mode** з тестовими даними.
