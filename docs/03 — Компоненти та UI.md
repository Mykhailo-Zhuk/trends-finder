# 03 — Компоненти та UI

## Дизайн-система

**Тема:** Glassmorphism, dark background (`#071212`), teal accent.

| Токен | Значення |
|---|---|
| Background | `#071212` |
| Glass surface | `rgba(255,255,255,0.06)` |
| Glass border | `rgba(255,255,255,0.10)` |
| Accent | `teal-400` / `teal-500` |
| Text primary | `rgba(255,255,255,0.90)` |
| Text muted | `rgba(255,255,255,0.40)` |
| Platform AliExpress | `orange-300` / `orange-500/15` |
| Platform Alibaba | `teal-300` / `teal-500/15` |

**Фони:** два ambient blur blobs + dot grid overlay (`opacity-[0.015]`).

**Шрифти (Google Fonts через CSS):**
- Display: `Syne` (заголовки, бейджі)
- Body: `DM Sans` (текст, картки)
- Mono: `DM Mono` (ціни, цифри)

## Компоненти

### `SearchForm.tsx`

Форма пошуку з react-hook-form + zod.

```tsx
<SearchForm
  onSearch={(query, platform) => search(query, platform)}
  isLoading={isLoading || isFetching}
  defaultQuery={query}
  defaultPlatform={platform}
/>
```

**Елементи:**
- Input з іконкою Search та валідацією
- Platform toggle (Обидві / AliExpress / Alibaba)
- Submit кнопка з Loader2 spinner під час завантаження

**Валідація (zod):**
- `query`: min 1, max 100, regexp `^[a-zA-Zа-яА-ЯіІїЇєЄ0-9\s\-.,&]+$`
- `platform`: enum `["aliexpress", "alibaba", "both"]`

### `ProductCard.tsx`

Картка товару для Grid view та Mobile fallback.

```
┌─────────────────┐
│ [AliExpress]    │  ← platform badge
│                 │
│   [Image]       │  ← 176px height, object-cover
│                 │
├─────────────────┤
│ Title (2 рядки) │
│ Seller          │
│ $12.99   ★4.8 🛒│
└─────────────────┘
```

**Props:** `product`, `onClick`, `index`
**Анімація:** `animate-slide-up` з `animationDelay: index * 40ms`

### `ProductsTable.tsx`

Таблиця для desktop (hidden на < md).

**Колонки:** Товар | Ціна | Рейтинг | Замовлень | Продавець | →

На mobile автоматично відображаються картки замість таблиці (через `md:hidden` fallback у `page-client.tsx`).

---

### `Charts.tsx`

Три типи графіків (Recharts):

| Компонент | Тип | Дані |
|---|---|---|
| `TopRatingChart` | BarChart | Топ 8 товарів за рейтингом |
| `PriceRangeChart` | BarChart | Розподіл товарів по 4 ціновим діапазонам |
| `PlatformChart` | PieChart (donut) | AliExpress vs Alibaba кількість |

Кастомний `CustomTooltip` в glassmorphism стилі.
`PlatformChart` не відображається, якщо тільки одна платформа.

---

### `Skeletons.tsx`

Shimmer loading стани:

| Компонент | Використання |
|---|---|
| `ProductCardSkeleton` | Grid view під час завантаження |
| `ChartSkeleton` | Charts view під час завантаження |
| `TableSkeleton` | Table view під час завантаження |

Shimmer ефект через CSS `before:` pseudo-element з `animate-shimmer`.

---

### `Pagination.tsx`

Пагінація з sliding window (max 5 кнопок).

```
← [1] [2] [3] [4] [5] →
```

Ховається якщо `totalPages <= 1`.

---

### `States.tsx`

Стани сторінки:

| Компонент | Коли відображається |
|---|---|
| `InitialState` | До першого пошуку |
| `EmptyState` | Пошук виконано, результатів немає |
| `ErrorState` | Помилка API або мережі |
| `DemoBanner` | Якщо `data.demo === true` |

`ErrorState` має кнопку "Спробувати знову" → `refetch()`.
`DemoBanner` — amber попередження про відсутність APIFY_API_TOKEN.

## View Modes (page-client.tsx)

Перемикач у правому верхньому куті результатів:

```
[⊞ Картки] [≡ Таблиця] [📊 Графіки]
```

| Mode | Desktop | Mobile |
|---|---|---|
| `grid` | 4 колонки | 2 колонки |
| `table` | Таблиця | Картки (fallback) |
| `charts` | 3 колонки | Стек |

## Анімації

| Анімація | Опис | Використання |
|---|---|---|
| `animate-fade-in` | opacity 0→1, 400ms | Стани, бейджі |
| `animate-slide-up` | translateY + opacity, 500ms | Картки, header |
| `animate-shimmer` | shimmer sweep | Skeleton |
| CSS hover | scale, shadow, border color | Картки |

## Крайні випадки

| Ситуація | Поведінка |
|---|---|
| Зображення не завантажилось | `onError` → `imgError = true` → `<Package>` placeholder |
| Title > 80 символів | `truncate(title, 80)` з `…` |
| `productUrl` порожній | `href="#"`, `preventDefault()` |
| `PlatformChart` — одна платформа | Компонент повертає `null` |
| Mobile + Table mode | Показує ProductCard grid замість таблиці |
