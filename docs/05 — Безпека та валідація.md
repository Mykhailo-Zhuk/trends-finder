# 05 — Безпека та валідація

## Головний принцип

```
Client → /api/search (Route Handler) → Apify API
```

**APIFY_API_TOKEN ніколи не потрапляє у браузер.**
Всі звернення до Apify — виключно через серверний Route Handler.

## Zod схеми (`src/lib/schemas.ts`)

### Форма пошуку (клієнт)

```typescript
export const searchFormSchema = z.object({
  query: z
    .string()
    .min(1, "Введіть пошуковий запит")
    .max(100, "Запит занадто довгий")
    .regex(
      /^[a-zA-Zа-яА-ЯіІїЇєЄ0-9\s\-.,&]+$/,
      "Запит містить недозволені символи"
    ),
  platform: z.enum(["aliexpress", "alibaba", "both"]),
});
```

### API параметри (сервер)

```typescript
export const searchApiSchema = z.object({
  query: z.string().min(1).max(100).regex(/^[a-zA-Zа-яА-ЯіІїЇєЄ0-9\s\-.,&]+$/),
  platform: z.enum(["aliexpress", "alibaba", "both"]),
  page: z.coerce.number().int().min(1).max(100).default(1),
  limit: z.coerce.number().int().min(1).max(50).default(20),
});
```

Валідація відбувається двічі: на клієнті (UX) і на сервері (безпека).

## Захист від XSS

- Дані з Apify рендеряться через React JSX — автоматичний escape
- `dangerouslySetInnerHTML` — не використовується ніде
- `imageUrl` передається в `src` атрибут `<img>` (не в innerHTML)
- `productUrl` — відкривається через `target="_blank"` з `rel="noopener noreferrer"`

## Захист секретів

| Змінна | Тип | Правило |
|---|---|---|
| `APIFY_API_TOKEN` | Серверна | Ніколи не `NEXT_PUBLIC_` |
| `UPSTASH_REDIS_REST_URL` | Серверна | Ніколи не `NEXT_PUBLIC_` |
| `UPSTASH_REDIS_REST_TOKEN` | Серверна | Ніколи не `NEXT_PUBLIC_` |

**Перевірка:** відкрити DevTools → Network → будь-який запит. У відповідях API token не повинен фігурувати.

## Acceptance Criteria безпеки

- [ ] APIFY_API_TOKEN не видно в DevTools → Network
- [ ] Rate limiting: > 10 req/min → 429
- [ ] Запит з символами `<script>` → 400 Bad Request (zod regexp)
- [ ] `page=999999` → 400 (zod max: 100)
- [ ] `limit=1000` → 400 (zod max: 50)
- [ ] Всі API відповіді мають security headers

## Route Handler — повний flow

```typescript
export async function GET(request: NextRequest) {
  // 1. Rate limit check
  const ip = request.headers.get("x-forwarded-for") ?? "unknown";
  if (!checkRateLimit(ip)) return 429;

  // 2. Zod validation
  const parsed = searchApiSchema.safeParse(rawParams);
  if (!parsed.success) return 400;

  // 3. Demo or real data
  if (DEMO_MODE) return getMockResults(...);
  const data = await searchProducts(...);  // server-only apify.ts

  // 4. Response з cache headers
  return NextResponse.json(data, {
    headers: { "Cache-Control": "public, s-maxage=300, stale-while-revalidate=600" }
  });
}
```

## Крайні випадки

| Ситуація | Поведінка |
|---|---|
| `APIFY_API_TOKEN` не встановлено | Demo mode (не помилка) |
| Запит без `query` параметра | Zod повертає 400 |
| IP не визначено | Fallback на `"unknown"` (спільний bucket) |
| Apify повертає 502 | Route Handler повертає 502 клієнту |
| Vercel Edge без Redis | Fallback на in-memory (не persistent між інстансами) |
